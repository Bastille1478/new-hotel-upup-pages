五钻酒店加项

一镜到底视频与钻级评定信息

一镜到底酒店实拍视频

  • 从酒店入口连续拍至酒店内部，呈现真实动线。
  • 覆盖公区及实际开放的设施设备，如健身房、会议室、洗衣房等。
  • 至少包含两个房间的视频画面。

钻级评定核心信息清单

  1. 基础信息：名称、地址、定位/特色、客房数。
  2. 区位交通：高铁站/机场/商圈车程及优势。
  3. 客房概况：主力房型、面积、配置及亮点。
  4. 餐饮配套：早餐、包间、大堂吧、菜系及场景。
  5. 会议宴会：数量、容量、场地优势及活动类型。
  6. 休闲配套：健身房、洗衣房、停车场、茶室/棋牌室、康养等。
  7. 酒店核心亮点：差异化、主打优势及适合客群。

开售前维护

3. 上线后基础流程维护

1. 财务结算 → 发票管理 → 携程应开发票开售前必做
2. 信息维护 → 酒店政策 → 早餐政策开售前必做
3. 信息维护 → 房型信息 → 新建房型开售前必做
4. 右上角用户名 → 合同管理

填写负责人信息，并签署合同。

5. 信息维护 → 待办任务

完成待办任务，信息分达到 90 分。

开售门槛：前 1–3 项均完成后，酒店才可以打开售卖。

4. 上线后陪跑运营维护方案

当前版本仅覆盖新签上线与基础维护。陪跑运营的具体节奏、经营目标、复盘频次和双方职责，待业务规则补充确认后再纳入本页；本页不构成未确认的服务承诺。
