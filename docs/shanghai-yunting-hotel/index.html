五钻酒店加项

一镜到底视频与钻级评定信息

一镜到底酒店实拍视频

  • 从酒店入口连续拍至酒店内部，呈现真实动线。
  • 覆盖公区及实际开放的设施设备，如健身房、会议室、洗衣房等。
  • 至少包含两个房间的视频画面。

钻级评定核心信息清单

  1. 基础信息：名称、地址、定位/特色、客房数。
  2. 客房概况：主力房型、面积、配置及亮点。
  3. 餐饮配套：早餐、包间、大堂吧、菜系及场景。
  4. 会议宴会：数量、容量、场地优势及活动类型。
  5. 休闲配套：健身房、洗衣房、停车场、茶室/棋牌室、康养等。
  6. 酒店核心亮点：差异化、主打优势及适合客群。

开售前维护

3. 上线后基础流程维护

1. 财务结算 → 发票管理 → 携程应开发票开售前必做
2. 信息维护 → 酒店政策 → 早餐政策开售前必做
3. 信息维护 → 房型信息 → 新建房型开售前必做
4. 右上角用户名 → 合同管理

填写负责人信息，并签署合同。

5. 信息维护 → 待办任务

完成待办任务，信息分达到 90 分。

开售门槛：前 1–3 项均完成后，酒店才可以打开售卖。

第 4 阶段｜开业初期曝光与转化运营

建立曝光、转化与价格基础

  • 报名商机中心新店激励相关活动，完成后续任务争取平台推流与资源曝光。
  • 完善长短标签、图文旅拍素材，突出酒店区位、产品、服务与差异化卖点。
  • 优先报名优享会、积分联盟、超级上新日等活动，争取 Banner、资源位和醒目标签。
  • 结合区位、酒店属性、竞品和适配客群，建立价格带、房型分层与渠道价格一致性。
  • 沟通制作优质套餐和预售产品，在开业初期引流、沉淀订单与评价。
  • 根据经营目标和预算，评估金字塔等付费推广并按投产优化。
